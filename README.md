# FacilityGym

Projeto acadêmico de uma microempresa digital de suplementos, acessórios e equipamentos para treino em casa.

## Estrutura

- `dist/index.html` — apresentação institucional da empresa
- `dist/loja.html` — página reservada para a loja demonstrativa
- `dist/styles.css` — identidade visual e responsividade
- `dist/script.js` — navegação para dispositivos móveis

Abra `dist/index.html` no navegador para visualizar o projeto.
